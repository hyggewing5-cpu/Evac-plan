# ผังอพยพหนีไฟ รพ.กองบิน บน.5 (3D)

เว็บแสดงผังอพยพ 3 มิติ (Three.js) ใช้งานบนมือถือและคอมพิวเตอร์ ไม่ต้องติดตั้งหรือ build

## ไฟล์
- `index.html` — ตัวเว็บ (ผังอาคาร เส้นทาง ก/ข/ค/ง และขั้นตอน)
- `config.js` — รายชื่อทีมและเบอร์โทร แก้ไขเฉพาะไฟล์นี้เมื่อเปลี่ยนตัวบุคคล
- `photos/` — รูปถ่ายสถานที่จริงประกอบแต่ละขั้นตอน (ชื่อไฟล์ตามรหัสขั้น เช่น `ก1.jpg` ดู `photos/README.txt`)
- `.nojekyll` — ให้ GitHub Pages เสิร์ฟไฟล์ตามปกติ

## เผยแพร่บน GitHub Pages
1. สร้าง repository แล้วอัปโหลดไฟล์ทั้งหมด
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`
3. เปิดลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## หมายเหตุ
- ต้องมีอินเทอร์เน็ตเพื่อโหลด three.js จาก cdnjs
- `config.js` มีชื่อบุคลากร หากใช้ repository สาธารณะ ควรพิจารณาก่อนเผยแพร่ หรือใช้ repository แบบ private

## การรองรับอุปกรณ์
- โทรศัพท์แนวตั้ง: แผนที่อยู่ด้านบน แผงข้อมูลและปุ่มอยู่ด้านล่าง
- โทรศัพท์แนวนอน / iPad / คอมพิวเตอร์: แผนที่ซ้าย แผงข้อมูลขวา ปุ่มเปลี่ยนขั้นปักอยู่ล่างสุดเสมอ
- รองรับรอยบากหน้าจอ (safe area), โหมดมืดอัตโนมัติ, ปุ่มสัมผัสขนาดไม่ต่ำกว่า 44 px
- สัมผัส: ลาก = หมุน, บีบ = ซูม, สองนิ้วลาก = เลื่อน | เมาส์: ลาก = หมุน, คลิกขวาหรือ Shift+ลาก = เลื่อน, ล้อ = ซูม
- คีย์บอร์ด: ← → เปลี่ยนขั้น, Space เล่น/หยุด, + − ซูม, 0 รีเซ็ตมุม, 1 / 2 เลือกชั้น, Esc ปิดหน้าต่าง
